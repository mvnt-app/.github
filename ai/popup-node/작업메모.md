# popup-node 작업 메모

2026-09-22. NFC 팝업 노드 웹. 실행 위치는 `popup-node/`. 조직 소개 `profile/` 은 건드리지 않는다.

## 문장

슬롯 3개. `question` 은 `SEEK` | `OFFER` | `IMAGINE`. 사용자가 적는 것은 `answer`.

IMAGINE만 고르기+자유문. 세계 예시를 여러 개 골라도 되고, 두 글자 이상 자기 말만 적어도 되고, 둘 다 해도 된다. `answer`는 고른 세계를 줄바꿈으로 잇고, 자기 말이 있으면 빈 줄 다음에 붙인다. SEEK와 OFFER는 짧은 문자열 그대로.

매칭. 선호 짝은 `SLOT_TARGETS` (SEEK↔OFFER, IMAGINE끼리). 내 문장은 상대 세 칸 전부와 비교하고, 선호 짝이 0.02 안이면 그 칸을 고른다. `pickIndex`.

밝기 `blendBand`:

- 질문을 하나만 켜면 그 칸 밝기 그대로.
- 여러 질문을 볼 때 강은 두 곳 이상이고 그중 강이 하나 이상, 또는 세 칸 중 중 이상이 둘.
- 한 곳만 강하면 중. 한 곳만 중이면 중, 한 곳만 약이면 약.
- 약한 겹침만 여러 개면 약으로 남긴다. 중으로 올리지 않는다.

글자 겹침은 0.55 이상이면 그대로, 0.28 이상이면 약 상한(`mid - 0.01`)까지만. 패널은 양쪽 문장과 한글 관계 문장. `components/MapScreen.tsx` `NodeRead`.

키 없음: `lib/match.ts` 테마. 강 0.72 / 중 0.42 / 약 0.22.
키 있음: 임베딩 코사인. 강 0.58 / 중 0.47 / 약 0.38. 짧은 한국어는 다시 맞춰야 한다.

시드 검증: `npm run check`. B는 세 칸 모두 강이라 전체가 강. 15는 IMAGINE만 중. 18은 SEEK↔OFFER의 아티스트 겹침만 약. 질문 하나만 켜면 B의 그 칸은 강을 유지한다.

시드 문장이 예전 질문/답이면 `question !== SEEK` 일 때 저장소가 시드를 덮어쓴다. IMAGINE이 예전 한국어 시드 문장이면 a·b·c·d의 그 칸만 새 세계로 바꾼다. 그 뒤에 사람이 고친 답은 덮지 않는다. 손님 노드는 덮지 않는다.

## 파일

- `app/page.tsx` 입구. A=`a` 코드 11, B=`b` 코드 12.
- `app/join/page.tsx` SEEK·OFFER 짧은 칸, IMAGINE 세계 칩 + 선택 문장. 홈 화면/알림.
- `app/map` `components/MapScreen.tsx` `components/Sky.tsx` 드래그, 휠, 핀치, 확대/축소/맞춤.
- `components/Header.tsx` 상단 종 → `/inbox`.
- `app/api/chat/[id]` 메시지. 상대 `push` 가 있으면 VAPID.
- `components/Notifier.tsx` 탭이 숨겨져 있고 푸시 구독이 없으면 Notification API.
- `lib/flags.ts` `testAgentsEnabled`. 값 없으면 로컬 true, `VERCEL` 이면 false. `true`/`false` 문자가 있으면 그 값을 따른다.
- `lib/store.ts` 파일 json, 또는 `DATABASE_URL` → `POSTGRES_URL` → `POSTGRES_PRISMA_URL`. 테스트 입구가 꺼지면 시드 a·b·c·d를 넣지 않는다. 맵에서도 `kind !== guest` 를 뺀다.
- `app/api/health` 배포 확인. `ok`, `database`, `testAgents`, `push`. 연결 문자열은 내려주지 않는다.
- 채운 노드는 밴드가 없어도 `dim` 으로 남긴다. 필터는 빛을 재는 질문만 바꾼다.
- `app/n/[token]` 태그 URL. 쿠키 `node_id`.

## 알림

아이폰은 홈 화면 추가 후에만 탭을 닫아도 푸시. `components/InstallCard.tsx`.
로컬 VAPID는 `data/vapid.json`. Vercel은 env. 없으면 푸시 구독만 건너뛰고 탭 알림은 동작.

## 고친 것

별자리 글자(노드 번호, SEEK/OFFER/IMAGINE, 약·중·강, NODE, 헤더 코드)는 JetBrains Mono. 답과 채팅 본문은 IBM Plex Sans KR. 한글이 모노에 없으면 플렉스로 떨어진다.

필터를 다 끄면 밝기만 세 질문으로 매긴다. 안 겹치는 노드도 희미한 점으로 남는다. 필터를 일부만 켜도 사람은 숨지 않고, 그 질문 기준으로 빛만 바뀐다. `ENABLE_TEST_AGENTS=false` 이면 손님만 보인다.

점은 납작한 동그라미 대신 약한 빛, 중간 빛, 밝은 헤일로. 나는 얇은 고리. 선은 가늘다.

맵의 홈 화면 카드는 뺐다. 가입 화면에는 그대로 있다.

채팅은 사람이 보낼 때만 쌓인다. 자동으로 들어가 있던 "결이 맞아", "OFFER가 맞아서 말을 건다." 는 저장소에서 지웠다.

채팅, 받은 말, 문장 고치기의 뒤로는 `router.back()`. 기록이 없을 때만 맵이나 입구로 간다.
