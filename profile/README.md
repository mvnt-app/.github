# MVNT

MVNT is building the choreography layer for AI-native media.  
We turn music into production-ready dance motion so creators and studios can ship faster across music, video, games, and UGC.  
Try it on [mvnt.studio](https://mvnt.studio) and explore our tooling on [GitHub](https://github.com/mvnt-app).  
Backed by Epic MegaGrants and focused on empowering creative freedom and choreographic IP.
